How to use DV026 Evidence · three different “greens”

Job: software gates + optional local Ollama Layer B. Ribbon has three groups — use one family at a time.

  • Single run — pick a command (phase-i, bundle, …) or Ollama slice/paired shortcuts.
  • Phase I sweep — repeats scripted phase-i across N seeds (reproducibility; not live LLM).
  • Ollama campaign — multi-model Layer B readiness; uncheck smoke and use 20 seeds for the full gate.
