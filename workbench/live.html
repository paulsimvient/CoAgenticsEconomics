How this console works

New Experiment — archive the current context and return to workflow start (cancel running campaign, clear READY display, unfreeze hypotheses). Prior evidence files stay on disk.

Preregistered hypotheses — freeze research expectations (SHA-bound) before a full campaign. Smoke mode skips freeze.

Proposal readiness (gates) — live MET / PROVISIONAL / PARTIAL / NOT YET against white-paper gate items (not the freeze form).

Bids — per-turn agent I/O from cell_*.jsonl: request → raw response → parsed BUY/SELL/HOLD.

Method — on each chart/table panel, expand how that number is calculated (read-only).

Workflow: Reset → qualify market (η>90%) → freeze preregistered hypotheses → start campaign → inspect bids.
