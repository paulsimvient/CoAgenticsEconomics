# v16: CoAgentics automated scientist + full CDA domain adapter

This version implements `ExperimentalDomain` with a twelve-trader, four-marginal-units-per-trader continuous double auction. The target buyer has a controlled mechanism; eleven other agents are constrained ZI controls. The scientist selects news-only, peer-only, or combined probes; the domain executes full control/treatment markets using the same pre-generated agent activation order and random quote variates. The observed outcome is the target's mean submitted quote; market efficiency, surplus, trades, and mean transaction price are secondary results. The evidence registry and hypothesis lifecycle remain those of CoAgentics v15.

**Important limits:** published marginal schedules are not yet transcribed; controlled mechanisms are not live LLMs; v15's linear expected response is not a calibrated predictor for endogenous CDA quote trajectories, so posterior probabilities are exploratory. Changed market state can change which target quotes are submitted, and matched random tapes do not equate endogenous market states. The next scientific milestone is calibration of model-conditional predictions using independent simulated training seeds, holdout coverage checks, and null false-discovery tests.
