# CoAgentics epistemics schema v1

These schemas define the discovery-side contracts that sit before the stable `coagentics.science.v1` evidence kernel.

They intentionally distinguish:

- a source assertion from an observation;
- hypothesis-generation material from confirming evidence;
- discovery/development data from sealed validation and prospective data;
- simulation-world claims from empirical-world claims;
- a single hypothesis from an explicit rival hypothesis set;
- experiment selection for information gain from policy optimization for mission utility.

Schema evolution must create a new version directory. Existing epistemic artifacts remain immutable.
