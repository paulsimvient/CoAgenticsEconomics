
## Protocol-controlled heterogeneous market (AV-1)

The C++ market now accepts a public-signal treatment per population. The heterogeneous campaign runner accepts a protocol assignment and writes per-cell raw inference evidence. `tools/av1_execute_market_plan.py` validates assignment plans, runs one matched cell at a time, verifies evidence, and hashes observation archives. This is a live Ollama path only; actual live experiments must still be run and independently reviewed. See `AV1_HOW_TO_MARKET_EXPERIMENT.md`.
