# V21 UI Refinement — Market Explorer

The market explorer is now organized around semantic zoom:

Campaign → Market → Event

The campaign layer emphasizes 84 independent sessions and their outcomes. Selecting a session moves attention to one 10-agent CDA. Scrubbing/replay moves to event-level evidence.

Refinements:
- compact campaign KPI strip
- clearer campaign/session hierarchy
- explicit semantic zoom cue
- denser completed-market table
- selected-market emphasis
- reduced panel height and whitespace
- clearer outcome terminology
- responsive behavior for narrower screens

The underlying read-only evidence semantics are unchanged.
