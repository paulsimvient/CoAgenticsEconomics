# Market Lab UI v2

This codebase retains the full EconomicGoagentics/CoAgentics implementation and adds the current Market Lab workbench UI concept as:

- `workbench/market_lab_workbench_v2.html`

The v2 UI is a standalone visual workbench prototype. It is intentionally not wired into the experiment backend yet. Existing backend, experiment, market, analysis, evidence, and live-server code remains intact.

Design hierarchy:

1. Market View — understand the experiment visually.
2. Measure — inspect hypotheses, outcomes, distributions, and counterfactuals.
3. Verify — trace an observed action into parsing, legality, execution, payoff, and evidence.

The prototype uses illustrative values only and must not be treated as experimental results.
