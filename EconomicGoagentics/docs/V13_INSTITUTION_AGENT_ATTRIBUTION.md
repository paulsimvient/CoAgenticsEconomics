# V13 — Institution-vs-Agent Attribution

V13 moves the controlled agent mechanisms and the ten-model campaign identity path into the v12 protocol-qualified CDA chamber.

The scientific control is ZI-C. Gode & Sunder (1993, DOI 10.1086/261868) showed that no-loss-constrained random traders can achieve very high allocative efficiency in a double auction, so efficiency by itself cannot be attributed to cognition. V13 therefore reports an institutional floor, an agent delta relative to that floor, and a matched intervention delta.

Controlled profiles are ZI-C, value-shading, signal-biased, and peer-anchored. Ten model IDs are used to qualify campaign orchestration. They are not ten live LLM executions. Live LLM experiments must enter through the v8 black-box harness and retain provider/model/version and raw-response provenance.

This is an attribution scaffold, not a causal claim from one metric. The next qualification step is to route live/replayed black-box model actions through this chamber and add bid-shading, price convergence, response latency, propagation, utility, and failure/abstention outcomes to the evidence record.
