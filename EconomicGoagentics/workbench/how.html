What is going on

This lab asks local language models (via Ollama) to trade in a small market. Each finished market is a cell. A campaign is a batch of those cells. The only page you need is Overview: Run, then Process, then Results.

If Process says RUNNING n/120 — a campaign is already going. Watch it. Do not click Start smoke or Start full. Cells show up under Results as they finish.
If Process says INTERRUPTED 84/120 — the runner is not alive. The 84 finished cells are still on disk and cannot be reconstructed. Inspect / Verify / Resume remaining / Export. Resume skips completed cells and will not overwrite them. If resume is blocked, keep those cells and run a new experiment.

The only URL

Open this, from a running workbench, in a browser:

http://127.0.0.1:8787/

Not a file on disk. Not /live.html. If the address bar starts with file://, the page cannot talk to the lab and you will see Failed to fetch.

To start the workbench from the project folder:

bash start-workbench.sh 8787

Use bash. iCloud often strips execute permission, so ./start-workbench.sh can fail.

The three blocks on Overview

1

Run — start (or refuse to start)

Start smoke is the first-run button: 2 models × 2 seeds. It skips Freeze and Layer A. Use it when nothing is running and Ollama is up.

Start full is the long catalog run. It stays disabled until Freeze H01 and Layer A have both succeeded, and while anything is already running.

Freeze H01 defaults locks the registered hypothesis so a full run has something frozen to test against. Run Layer A checks the market engine itself (not the LLMs).

2

Process — the live campaign

This is the Ollama / hetero runner. RUNNING 76/120 means 76 cells are done, 120 is the plan, and one cell is in flight. The line under the bar is the current design, seed, and ETA.

Idle copy is Idle — no campaign. That is different from Stopped (you cancelled, some cells may already be saved) and from INTERRUPTED (the process died; finished cells remain).

Stop only appears while a campaign is running. Do not start a second campaign to “fix” a slow bar. RUNNING is true only when the C++ process identity is live — not because a file is new.

3

Results — finished cells

Each row is one finished market (design × seed). Click a row: Asked is what the model was sent; Replied is what it returned (often JSON like HOLD / BUY / SELL).

An empty table while Process is RUNNING only means no cell has finished yet — not that the campaign failed.

There are two runners. Only one is yours.

The experiment: Ollama models step through a market. Progress is Process + Results. Files land under results/dv026_heterogeneous_campaign/.

Not the experiment: a paced C++ toy market used by older UI. Empty chart, “C++ LIVE MARKET,” order book with no trades. It can be idle while the real campaign is at 76/120.

What you should do

  1. Stay on http://127.0.0.1:8787/.
  2. If Process says RUNNING, wait. Click Results rows if you want to see a prompt and a reply.
  3. If Process says INTERRUPTED, do not start a second campaign to replace it. The finished cells are the observations. Verify, then resume remaining cells, or export and keep them.
  4. When it hits complete, read the table. Do not treat completion as a scientific claim — that is a later, gated step.
  5. Next time, from a cold start: confirm Ollama is up, click Start smoke, watch Process, then consider Freeze + Layer A + Start full.
Do not start smoke or full while one campaign is running. Do not open interface.html from Finder. Do not use /live.html as the watch surface (that page is an advanced console). Do not kill the workbench hoping it will restart the campaign — the campaign is a separate C++ process; the page only reports it.

Visualize & Analyze

This is a two-level explorer. The top plot is the archive of completed markets (each completed cell is one CDA session), plus a cream band for cells not yet run. Click a completed point to open that market: 10 agents around a recorded order book. Grey dashed lines are resting archived bids; orange is a recorded trade. η is the session outcome from cell_evidence. Replay does not invent motion and does not resume the campaign.

Overview is the continuation console: Inspect the archive, Verify, then Resume remaining. That starts only unfinished cells (84–119 on the current run) and refuses to overwrite the archive.

Sidebar pages

Overview is the operator path. Visualize & Analyze is the read-only market lab. Experiment Builder, Evidence, Validation, Portfolio, Ask, and the Research Console at /live.html are extra surfaces. They do not replace Run / Process / Results, and several of them still show older chrome. If you get lost, come back here, then click Overview.
